# 🔐 Simple Authentication System (.NET + MySQL)

This project is a simple authentication system built using **C#**, **.NET**, and **MySQL**. It demonstrates basic user authentication functionality including user registration, login validation, and database connectivity. The project was developed for learning purposes to understand authentication workflows and backend development using .NET.

---

## 🚀 Features
- User Registration
- User Login Authentication
- MySQL Database Integration
- Input Validation
- Basic Authentication Logic

---

## 🛠️ Technologies Used
- C#
- .NET / .NET Framework
- MySQL
- ADO.NET / MySQL Connector
- Visual Studio
